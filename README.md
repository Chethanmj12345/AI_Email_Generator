# AI Email Generator

## Project Description
AI Email Generator is a web application that generates professional emails using Google Gemini AI.

## Features
- Generate professional emails
- User-friendly interface
- AI-powered email generation

## Technologies Used
- Python
- Flask
- HTML
- CSS
- Google Gemini API

## Installation

1. Clone the repository

git clone https://github.com/Chethanmj12345/AI_Email_Generator.git

2. Go to project folder

cd AI_Email_Generator

3. Install dependencies

pip install -r requirements.txt

4. Run the application

python app.py

5. Open the browser

http://127.0.0.1:5000
